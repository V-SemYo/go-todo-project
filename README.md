# Планировщик задач (TODO-лист)
Это полноценный веб-сервер, который выполняет роль планировщика задач — аналога ежедневника или списка дел.

# Что умеет проект?
Сервер позволяет через удобный веб-интерфейс управлять списком своих задач:

- Добавлять задачи с заголовком, комментарием и датой
- Редактировать уже существующие задачи
- Удалять ненужные задачи
- Отмечать задачи выполненными — одноразовые удалятся, а повторяющиеся переместятся на следующую дату по заданному правилу
- Просматривать список ближайших задач с сортировкой по дате
- Искать задачи по ключевым словам или на конкретную дату
- При желании можно защитить доступ паролем

Задачи могут быть как одноразовыми, так и повторяющимися.

# Что я сделал из задач повышенной сложности (звёздочек)
- Порт можно задать через переменную окружения "TODO_PORT"
- Путь к файлу базы данных — через "TODO_DBFILE"
- Поиск задач по тексту и по дате (/api/tasks?search=...)
- Поддержка сложных правил повторения:  
  - w 1,3,5 — задачи по понедельникам, средам, пятницам  
  - m 1,15 или m -1 — задачи в определённые дни месяца или последний день  
- Аутентификация через JWT (пароль задаётся в "TODO_PASSWORD")
- Dockerfile для сборки образа

# Инструкция по запуску кода локально
- Установленный язык Go (версии 1.21 или новее). Если нет — скачай с официального сайта.
- Любой современный браузер
- Склонируй репозиторий и перейди в папку:
git clone https://github.com/V-SemYo/go-todo-project.git
cd go-todo-project
- Скачай зависимости
go mod download
- Запусти сервер
go run main.go (сервер запустится по адресу: http://localhost:7540)
P.S если хочется проверить аутентификацию, то делаем:
export TODO_PASSWORD=777(или любой ваш пароль)
go run main.go

# Инструкция по запуску тестов
- Настройки в tests/settings.go

var Port = 7540                    // порт сервера
var DBFile = "../scheduler.db"     // путь к БД
var FullNextDate = true            // проверять w и m правила
var Search = true                  // проверять поиск по дате/тексту
var Token = "..."                  // JWT-токен (если используется пароль)
(если TODO_PASSWORD задан делаем:
curl -X POST http://localhost:7540/api/signin \
  -H "Content-Type: application/json" \
  -d '{"password":"777"}'
)
и полученный токен вставить в var Token = "..."

- Для запуска всех тестов
go test ./tests

# Инструкция по сборке и запуску через Docker
- Сборка образа
docker build -t scheduler-app .

- Запуск (без сохранения БД)
docker run -p 7540:7540 scheduler-app

- С пробросом БД на локальную папку (задачи будут сохранятся)
docker run -p 7540:7540 -v $(pwd)/data:/app/data scheduler-app

- С указанием пароля
docker run -p 7540:7540 -e TODO_PASSWORD=777 scheduler-app
